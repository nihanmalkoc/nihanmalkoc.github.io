Room List (ID-RML)

Automation tool 03 · PowerShell + AutoLISP + Excel
01Delivery Sets 02Drawing List (TML) 03Room List (ID-RML)

The room material list (ID-RML) gives every room of the interior package: code, name, area, perimeter, and floor, ceiling, wall and skirting finishes. All of it already sits in the room tags of the room base drawings. This tool extracts the tags from the xrefs headless and builds the list from the office template, one sheet per building. On the last delivery: 2,056 rooms from 44 room drawings, about 22 hours of work by hand.

The Problem

By hand, someone opens each room drawing, copies every tag into Excel, sorts the rooms by level, totals the areas and checks the codes, for every building and again after every change to the plans. The tags themselves are mixed: older and newer tag blocks name the same field differently, in Turkish or in English, and a room copied from another floor keeps a code that no longer fits.

How It Works

An AutoLISP routine reads every attributed block in the model space of each room drawing, with no AutoCAD window. PowerShell turns the tags into rooms, checks them, and writes each building onto its own sheet copied from the office template.

Room xrefs→ Read tags headless→ Check codes→ Sort by level→ Fill the template→ One sheet per building
  • Fields mapped to a list of tag names each, so old and new tag blocks can be mixed.
  • Areas written as text (21.80m²) become numbers; building, level and number come from the room code.
  • Checks: duplicate codes, codes in the wrong format, and tags whose code names another building or level than the drawing they sit in.
  • Order: rooms sorted by level, basement to roof, then by room number.
  • Template: header with project, building name and date, office and client logos, one formatted row per room.
  • Totals: the building area as a sum formula, so the sheet stays live in Excel.

Designed to Be Safe

It only reads: no drawing is ever changed. Drawings open in AutoCAD are skipped and reported, to be read again once they are closed. The template is never modified and an existing list is never overwritten.

Results

On the last delivery the list covered 2,056 rooms from 44 room drawings across the buildings, work estimated at about 22 hours by hand. Because it reads the drawings instead of a copy of them, the list can be rebuilt whenever the room plans change, and the code check finds the rooms that would have gone into the list with the wrong number.
