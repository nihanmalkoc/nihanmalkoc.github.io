AutoCAD Delivery Tools

Practice automation · PowerShell + AutoLISP

A batch toolkit that keeps hundreds of AutoCAD delivery sets consistent: which base drawings each sheet references, how files, layouts and xrefs are named, title block date and revision, and bound, xref-free copies for issue. It runs headless through AutoCAD's console, so a re-issue that kept a team of 10 busy for a full day now takes about half an hour.

The Problem

On large projects every sheet is its own drawing that overlays a stack of base drawings (plan, structure, facade, rooms, dimensions, doors, FFE …) plus a sheet border. Each package needs a different stack, and over months of revisions sets drift: a missing xref here, a duplicate there, an old border, a layout still named after a copied file. Before every issue someone opened hundreds of drawings by hand to check them, update the title block and bind a clean copy, which was slow and easy to get wrong under deadline pressure.

How It Works

The office agrees on its rules once, in a single JSON config: naming patterns, which base drawings each package references, title block tags and draw order. A PowerShell module then generates AutoLISP scripts and runs them through accoreconsole, with no AutoCAD window, several drawings at a time.

Config→ Xref report→ Fix plan→ Review→ Apply→ Title block→ Bound delivery set

Designed to Be Safe

Nothing changes until a human has read the plan. Drawings open in AutoCAD are skipped, a drawing whose report is incomplete is never planned, and bound copies are written only when every xref bound cleanly and never over an existing file. The source sets always stay unbound.

Results

Measured on a real re-issue of about 330 sheets over a network share, 4 parallel processes: title block update ≈ 7.5 min, bind and save ≈ 10 min, checking the few failures ≈ 10 min, roughly half an hour in total for work that used to take a team of 10 people a full day. The Excel rules and status workbooks also gave the team one shared view of what every package should contain and where each set stands.
