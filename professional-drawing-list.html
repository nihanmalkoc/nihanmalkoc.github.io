Drawing List (TML)

Automation tool 02 · PowerShell + AutoLISP + Excel
00Delivery App 01Delivery Sets 02Drawing List (TML) 03Room List (ID-RML)

The drawing list (TML) is the Excel register of every sheet in a delivery: code, revision, scale, date, English and Turkish name and sheet size. This tool reads the title block of every delivered sheet and writes the list from the drawings, in the list's own style, so the list and the drawings stop disagreeing. On the last delivery it added 488 missing sheets, about 27 hours of typing and checking by hand.

The Problem

Sheets come from several teams, and one drawing can hold more than one sheet. Every sheet has to appear in the list once, in its package block and in the right order, numbered, with the same name, scale and size as its title block, and legend pages sit directly above the plan they belong to. Typed by hand, the list falls behind: by delivery day 488 sheets were missing from it, mostly sets from other teams and new interior sets.

How It Works

An AutoLISP routine reads each title block headless: layout, revision, scale, date, English and Turkish name, and the sheet size from the border block, or from the layout paper when a team uses its own border. PowerShell compares the codes with every worksheet of the list and adds only what is missing, following the rules of the list itself.

Delivered drawings→ Title block survey→ Compare with the list→ Plan the rows→ Review→ Write in the list's style
  • Worksheet: the nearest folder named like a worksheet, otherwise the building in the sheet code.
  • Position: after the last row of its package; a new package becomes its own block in the office package order, with a separator row.
  • Legend pages directly above the plan they belong to, in order: 0000, 0001, plan.
  • Style: new rows copy the sheet's own row format (borders, fonts, fill, number format, row height); formulas kept.
  • Numbering renewed on every changed worksheet; the print area grows with the table.
  • Values written the way the list writes them: 1:20 becomes 1/20, text stays text.
  • The other direction: sheet names go from the list into the title blocks, fitted to the line.
  • Sync: revision, scale, date and size go from the drawings back into the list.

Designed to Be Safe

The list is never written while it is open in Excel, and a backup copy is taken before every save. A report-only run makes the same changes in memory and saves nothing, so the rows it reports are exactly the rows a real run writes. Run it twice and the second run adds nothing.

Results

Tested on a copy of the live list: rows deleted from it came back at exactly their original positions, with the same format, and a survey of the whole delivery (493 title blocks in 130 drawings) matched the list with no sheet missing. On the last delivery it added 488 sheets, work estimated at about 27 hours by hand, and the list became the single source for the sheet names in the title blocks.
